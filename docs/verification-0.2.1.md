# Program Manager 0.2.1 검증 기록

검증일: 2026-09-10. Windows 10 Pro 64비트(10.0.19045), 실제 배율 250%(240 DPI), .NET 8 및 .NET Framework 4.8.

트레이 우클릭 메뉴 상단에 Manager에서 실행한 등록 프로그램을 최근 순서로 최대 5개 표시합니다. 같은 프로그램은 중복하지 않으며 실행 버튼·더블클릭·Enter·트레이 실행이 같은 기록을 사용합니다. 기록은 재시작 후에도 유지하고 등록 이름·경로 변경을 반영합니다. 등록을 제거하면 최근 메뉴에서도 사라집니다. 기존 설정은 그대로 읽으며 과거 실행 이력을 임의로 채우지 않습니다.

## 검사 결과

- 두 런타임에서 7개 실행 후 최근 5개 유지, 중복 제거, 저장·재로딩, 이름 변경과 등록 제거, 검색 필터와 독립된 메뉴를 검사했습니다.
- 파일이 없으면 메뉴를 비활성화하고 실행 실패 시 기록을 변경하지 않습니다. 설정 파일 잠금으로 저장에 실패하면 기존 파일과 메모리 기록을 보존합니다.
- 격리된 데이터 폴더에서 인수 없는 Windows `rundll32.exe`로 실제 트레이 메뉴 클릭과 기록 저장을 검사했습니다. 현재 등록 경로를 다시 확인하므로 편집 전 경로가 남은 호출도 현재 등록을 실행합니다. 사용자 프로그램은 시험 실행하지 않았습니다.
- 두 런타임의 네이티브 메뉴를 렌더링해 5개 항목의 배치와 `&` 문자 표시를 확인했습니다. 결과는 `artifacts/tray-0.2.1/net8`, `artifacts/tray-0.2.1/net48`에 있습니다.
- `tools/build.ps1` 전체 통과: 두 제품 빌드, Core/데스크톱 검사, 기존 120개 UI 화면 검사, 런타임 간 양방향 TLS 통신, Windows 10/11·Windows 7 설치 파일 생성. 빌드 경고와 오류는 0개입니다. 로그는 `artifacts/build-0.2.1.log`입니다.

## 현재 PC 설치

기존 0.2.0을 0.2.1로 업데이트했습니다. 설치 종료 코드 0, 설치된 465개 파일의 해시가 최종 게시 폴더와 일치합니다. 기존 프로그램 19개를 보존했으며 설치 전후와 새 앱 실행 후 설정 파일이 바이트 단위로 동일합니다. 설치본의 실제 창 제목 `Program Manager 0.2.1`과 `내 프로그램 19개` 표시를 확인했습니다. 새 실행 기록은 아직 0개이며 이후 Manager에서 실행한 항목부터 기록합니다.

설치 파일 크기는 Windows 10/11용 51,045,598바이트, Windows 7용 2,401,026바이트입니다. 설치 증거는 `artifacts/upgrade-verification-0.2.1.json`, `artifacts/upgrade-0.2.1.log`, 해시는 `artifacts/installers/SHA256SUMS.txt`에 있습니다.

Windows 7 실기기와 두 번째 물리 PC에서의 검증은 수행하지 않았습니다. Windows 7용 코드는 이 PC의 .NET Framework 4.8에서 검사했습니다. 프로젝트에 GitHub 원격 저장소가 없어 원격 게시를 수행하지 않았습니다. 기존 GitHub 배포 기능의 실제 전송 검증은 [0.2.0 기록](verification-0.2.0.md)을 참고하세요.
