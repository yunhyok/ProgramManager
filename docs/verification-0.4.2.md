# Program Manager 0.4.2 검증 기록

클라이언트 목록 새로고침은 인증된 호스트에서 GitHub 릴리스 동기화를 요청하고 완료된 카탈로그를 받습니다. 일반 연결 확인·설치 파일 검증용 목록 조회는 기존의 빠른 조회를 유지합니다. 동시에 들어온 새로고침은 진행 중인 조회를 공유합니다. 저장소별 실패와 호스트 인터넷·설정 문제는 기존 카탈로그를 보존하며 클라이언트에 안내합니다. 설치 파일은 미리 다운로드하지 않습니다.

클라이언트 역할이면 메인 화면에서 호스트 관리 탭 전체를 제거하고, 설정 적용으로 호스트 역할을 켜면 복원합니다. 목록 갱신 중 비활성화된 부모 컨트롤의 `Enabled` 값을 설치 버튼 판단에 사용하던 오류를 수정했습니다.

추가한 검사는 실제 인증서 고정 TLS 요청으로 새 버전 반영, 동시 요청 공유, 인증 거절, 실패 시 기존 버전 유지, 재시도 후 안내 해제, 설치 파일 다운로드 0회를 확인합니다. 실제 트레이의 업데이트 확인도 호스트 새로고침을 요청하는지 검사합니다. UI 검사는 역할 전환, 목록 갱신 성공·실패 후 버튼 복구, 빈 검색, 다른 Windows 선택, 설치 파일 없는 항목을 확인합니다.

Windows 7용 런타임 검사는 현재 Windows에서 .NET Framework 4.8로 실행합니다. 실제 Windows 7 장비와 별도 물리 클라이언트의 실행 검사는 포함하지 않습니다.

2026-09-16 `tools/build.ps1` 전체 검증을 통과했습니다. .NET 8 / .NET Framework 4.8 Core·Desktop 검사, 양방향 교차 런타임 TLS 전송, 실제 모니터 및 100/125/150/200/250% 화면 배율 검사(생략 0개), 두 설치 파일과 SHA-256 목록 생성을 완료했습니다. 실제 폼을 그린 클라이언트 전용 화면에서도 호스트 탭 없이 설치 버튼과 목록이 표시됩니다. 로그와 화면은 로컬 `artifacts/build-0.4.2.log`, `artifacts/layout/`에 있습니다.
