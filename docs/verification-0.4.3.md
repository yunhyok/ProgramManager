# Program Manager 0.4.3 검증 기록

실제 `simple-pi-calculator` 오프라인 설명 캐시에서 `<p align="center">`, `<h1>` 등이 이스케이프된 글자로 표시되는 문제를 확인했습니다. 원인은 호스트가 README의 HTML까지 모두 텍스트로 변환하던 제한된 렌더러였습니다.

README와 릴리스 본문을 Markdown으로 변환한 뒤 HTML 파서로 읽고, 허용된 표시용 태그와 속성만 다시 생성합니다. 제목·목록·표·강조·문서 내부 링크를 지원하며 코드 블록의 태그 예제는 그대로 보존합니다. 스크립트, 이벤트, 외부 리소스와 스타일은 전달하지 않습니다. 이미지에는 대체 설명을 표시합니다. Markdig 1.3.2와 HtmlAgilityPack 1.13.0을 사용하며 라이선스 고지를 설치 파일에 포함합니다.

문서 캐시 키를 변경해 업그레이드 후 첫 설명 요청에서 새 페이지를 생성합니다. 기존 형식의 HTML 캐시를 준비한 회귀 검사에서도 새 문서가 내려오는지 확인했습니다.

실제 Windows HTML 창으로 혼합 HTML/Markdown, 코드 예제, 표·목록·강조와 실행 요소 제거를 검사했습니다. 화면 확대와 창 크기 변경 시 본문이 오른쪽으로 밀리던 문제도 수정했으며, 문서 전체 너비가 뷰어 너비 안에 들어오는지 확인합니다. .NET 8 및 .NET Framework 4.8에서 실제 `simple-pi-calculator` README를 표시하고 렌더링 이미지를 확인했습니다. 자료는 로컬 `artifacts/offline-docs-0.4.3/`에 있습니다.

2026-09-16 GitHub에서 확인한 `simple-pi-calculator` 최신 릴리스는 [v0.3.1](https://github.com/yunhyok/simple-pi-calculator/releases/tag/v0.3.1), 커밋 `2820dfb7`입니다. 해당 앱의 소스나 릴리스를 변경하지 않았습니다. README 표시만 Program Manager에서 검증했습니다.

화면 공통 스타일도 정리했습니다. 네이티브 Windows 드롭다운의 항목 높이와 레이아웃 최소 높이를 버튼과 같은 38 논리 픽셀 기준으로 맞췄습니다. 검색·입력 필드의 여백, 기본/보조 버튼, 선택 탭 표시, 목록 헤더·행, 설명 영역을 일관되게 배치합니다. 키보드와 접근성 인터페이스는 Windows 기본 컨트롤을 유지합니다. 기존 확대 배율 검사에 드롭다운/설치 버튼 및 검색창/새로고침 버튼의 높이·상단 정렬 비교를 추가했습니다.

.NET 8 및 .NET Framework 4.8의 코어·데스크톱 검사, 실제 배율과 100/125/150/200/250% 모의 배율 검사를 모두 통과했습니다. 배율 검사에서 건너뛴 항목은 없습니다. 현재 PC의 실제 250% 배율에서 Windows 선택·설치 버튼·검색창·새로고침 버튼은 모두 높이 95px, 도구 모음 상단 10px로 일치합니다. 등록/설정 창의 초기 DPI 배율 중복 적용 및 입력칸 너비 축소를 방지하는 검사도 포함합니다. 이 검사는 현재 Windows의 두 실행 환경에서 수행하며 별도 Windows 7 PC에서 실행한 결과는 아닙니다.

최신 v0.3.1을 동기화한 실제 0.4.2 호스트에서도 설명 HTML에 이스케이프된 `<p>`가 남아 있고 제목·표 요소가 생성되지 않는 것을 내부망 요청으로 재현했습니다. 해당 앱의 최신 릴리스와 별개로 Manager의 문서 생성 수정이 필요한 문제임을 확인했습니다.

배포 커밋은 `7880b72704c30e4eeff9943eaf6e9de62efac9c0`입니다. [태그 CI 35046637381](https://github.com/yunhyok/ProgramManager/actions/runs/35046637381)와 main CI 35046639920이 모두 성공했으며, [v0.4.3 릴리스](https://github.com/yunhyok/ProgramManager/releases/tag/v0.4.3)에 두 설치 파일과 SHA256SUMS.txt가 게시됐습니다.

- Windows 10/11 설치 파일: 51,276,483 bytes, SHA-256 `541db01ed3992bb44c09c483df611e3c3eeb2768cbed923eb3617b55eba6d35a`
- Windows 7/8 설치 파일: 2,638,280 bytes, SHA-256 `b0d7d30fd046228f13c5f72983bf8e128dfba2a1e138d02e05c0492cf7461e36`

실제 게시 파일을 자동 업데이트 코드로 내려받아 해시·설치 제품 정보를 검증했습니다. 인터넷 접근을 차단한 검사 클라이언트에서도 인증된 호스트를 통해 같은 파일을 받았습니다. 현재 PC는 이 게시본으로 업데이트했으며 설치 실행 파일의 제품 버전이 `0.4.3+7880b72704c30e4eeff9943eaf6e9de62efac9c0`인 것을 확인했습니다. 등록 프로그램 19개, GitHub 선택 10개, 실행 경로와 연결 설정을 보존했고, 이전 설치 파일 백업·자동 재시작도 확인했습니다. 새 문서 라이브러리와 라이선스 고지가 설치 폴더에 있습니다.

설치 후 실제 호스트에 목록 갱신과 `simple-pi-calculator` 설명을 다시 요청했습니다. 배포 버전은 0.3.1, 경고는 없었으며 HTML 제목과 표가 생성되고 이스케이프된 문단 태그가 사라졌습니다. 업데이트 전후 결과는 로컬 `artifacts/offline-document-before-0.4.3.json`과 `artifacts/offline-document-after-0.4.3.json`에 기록했습니다.
