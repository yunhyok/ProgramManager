Program Manager 0.1.0

트레이 한 곳에서 프로그램을 실행하고, 다른 컴퓨터에 배포할 버전을 관리합니다.

시작 메뉴에서 Program Manager를 실행합니다. 설치 시 바탕화면 바로가기는 기본으로 만들지 않습니다. 자동 실행을 선택하면 Windows 로그인 후 트레이에서 시작합니다.

1. 프로그램 목록 정리

  1. 로컬 프로그램 등록 기능에서 이름과 실행 파일(.exe) 또는 바로가기(.lnk)를 선택합니다. 바로가기는 Manager의 shortcuts 폴더로 복사됩니다. 등록 후 실행을 확인했다면 바탕화면 바로가기는 정리해도 됩니다. 실행 파일 자체는 원래 설치 위치를 유지하세요.
  2. 목록에서 등록한 프로그램을 선택해 실행합니다. 파일은 원래 위치에 그대로 둡니다.
  3. 창의 닫기 버튼을 누르면 트레이에 남습니다. 오른쪽 아래 트레이 아이콘을 한 번 클릭하면 목록이 다시 열립니다.

아이콘이 보이지 않으면 Windows 트레이의 숨겨진 아이콘 영역을 확인하세요. 완전히 종료하려면 트레이 메뉴의 종료를 선택합니다. 목록에서 항목을 제거해도 대상 프로그램 파일은 삭제하지 않습니다.

2. 개발 컴퓨터를 호스트로 설정

  1. 옵션에서 호스트 + 클라이언트 역할을 선택합니다. 일반 사용 컴퓨터는 클라이언트로 설정합니다.
  2. 다른 컴퓨터에서 접근 가능한 호스트 이름 또는 IP 주소와 포트를 확인합니다. 기본 TCP 포트는 45672입니다.
  3. 배포할 프로그램의 EXE/MSI 설치 파일과 아래 정보를 등록합니다.
  4. 호스트의 연결 코드를 내보내 사용할 클라이언트에 전달합니다.

호스트는 게시 시 설치 파일을 저장소에 복사하고 크기·SHA-256 정보를 기록합니다. 새 버전은 같은 프로그램 ID로 게시하세요. 설치 프로그램 자체도 기존 설치를 업데이트하도록 구성되어 있어야 합니다.

호스트가 파일을 제공하려면 해당 컴퓨터의 사용자가 로그인해 있고 Program Manager가 실행 중이어야 합니다. 창을 닫아 트레이에 두는 것은 괜찮지만 종료·로그아웃·절전 중에는 새 다운로드를 제공하지 못합니다.

3. 다른 컴퓨터에서 연결

  1. 클라이언트의 옵션을 열고 호스트에서 받은 연결 코드를 붙여 넣습니다.
  2. 호스트 목록을 새로 고쳐 연결을 확인합니다.
  3. 프로그램 설명, 버전과 변경 이력을 확인합니다. 이 컴퓨터의 OS에 맞는 설치 파일이 사용됩니다.

연결 코드는 호스트 주소·포트·인증서 지문·공유 비밀을 함께 담고 있습니다. 신뢰하는 방법으로 전달하고 공개 문서나 스크린샷에 노출하지 마세요. TLS 1.2 연결에서 클라이언트는 등록한 인증서 지문으로 호스트를 확인하고, 호스트는 공유 비밀로 클라이언트의 접근을 확인합니다.

호스트 이름 또는 IP 주소를 바꾸면 새 연결 코드를 받아 등록하세요. 인증서가 달라졌다는 오류가 나타나면 호스트 설정을 확인한 뒤 올바른 코드를 다시 받아야 합니다.

4. 설치와 업데이트

  1. 호스트 목록을 새로 고치고 프로그램의 현재 버전과 변경 내용을 확인합니다.
  2. 원하는 프로그램의 설치 또는 업데이트를 직접 선택합니다.
  3. 다운로드가 끝나면 크기와 SHA-256 검증을 통과한 설치 파일을 실행합니다. 대상 설치 프로그램의 화면을 따라 진행합니다.
  4. 설치가 끝난 뒤 로컬 실행 파일 또는 바로가기를 확인합니다. 설치 종료 코드와 실행 경로 확인을 마쳐야 Manager가 설치 버전을 기록합니다.

설치 프로그램이 관리자 권한을 요청할 수 있습니다. 설치 취소나 실패를 성공으로 기록하지 않습니다. 이미 설치한 프로그램이라도 설치 위치가 달라졌다면 새 실행 경로를 지정하세요.

이미 설치된 프로그램은 기존 설치 연결 기능에서 실행 경로와 확인한 버전을 등록할 수 있습니다. 버전을 모르면 비워 두세요. 호스트의 최신 버전이 이미 설치되어 있다고 자동으로 가정하지 않습니다.

다운로드 도중에는 .part 임시 파일을 사용합니다. 검증되지 않은 파일은 설치에 사용하지 않습니다. 호스트는 클라이언트에 원격 무인 설치를 실행하지 않습니다.

문제 해결

상황확인할 사항
호스트에 연결되지 않음호스트의 로그인·프로그램 실행·절전 상태, 주소와 포트를 확인하세요. 같은 내부망에서 접근 가능해야 합니다. 필요하면 사용자가 Windows 방화벽의 개인 네트워크에서 해당 TCP 포트를 허용하세요.
이 컴퓨터용 설치 파일이 없음호스트에 해당 OS용 릴리스가 게시되어 있는지 확인하세요. 다른 OS용 파일을 대신 설치하지 않습니다.
다운로드 검증 실패호스트 목록을 새로 고쳐 다시 받으세요. 계속 실패하면 호스트의 원본 설치 파일과 게시 내용을 확인하세요.
설치 후 실행되지 않음실제 설치된 EXE 또는 바로가기의 위치를 다시 확인하세요. 대상 프로그램의 자체 실행 오류도 확인해야 합니다.
Windows 7 설치에서 .NET 안내가 나옴Microsoft의 .NET Framework 4.8을 먼저 설치한 뒤 Manager 설치를 다시 실행하세요. 설치 프로그램은 런타임을 자동 다운로드하지 않습니다.
설정 또는 인증 파일 오류기존 파일을 보존한 채 오류를 확인하세요. 보호된 인증 정보는 다른 Windows 사용자나 PC로 복사해 사용할 수 없습니다.

데이터 위치와 동작 범위

기본 데이터 폴더는 %LOCALAPPDATA%\ProgramManager입니다. settings.json은 설정, repository는 배포 저장소, identity는 보호된 호스트 인증 정보, downloads는 다운로드, cache.json은 마지막 호스트 목록입니다. 프로그램 제거 시 이 사용자 데이터는 보존합니다.

--tray는 트레이 시작, --data-dir "폴더 경로"는 별도 데이터 폴더 실행 옵션입니다. 일반 사용에서는 기본 경로를 사용하면 됩니다.

0.1.0은 내부망에서 수동 연결과 사용자가 선택하는 설치를 제공합니다. 인터넷 중계, 공유기 포트 개방, 자동 롤백, 호스트 자동 검색, Windows 서비스는 포함하지 않습니다. 실제 Windows 7 PC와 두 번째 물리 PC에서의 설치·통신은 별도 확인이 필요합니다.

Program Manager 0.1.0 · 설치에 포함된 오프라인 도움말 · 외부 연결 없이 읽을 수 있습니다.
