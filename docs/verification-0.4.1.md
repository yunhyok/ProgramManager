# Program Manager 0.4.1 검증

2026-09-10. 트레이의 배포 앱 확인과 Manager 자체 확인을 **업데이트 확인** 하나로 통합했습니다. 호스트·클라이언트 역할별 업데이트 항목을 두지 않습니다.

- 새 버전이 없으면 업데이트 대상 메뉴를 숨깁니다.
- 새 버전이 있으면 **업데이트 N개** 안에 Program Manager와 배포 앱의 이름·현재 버전·새 버전을 표시합니다. Manager 자체 업데이트도 트레이 아이콘 표시와 개수에 포함됩니다.
- 확인만으로 설치하거나 설치 파일을 다운로드하지 않습니다. 목록에서 대상을 선택한 뒤 설치를 확인합니다.
- 확인 중에는 중복 확인·업데이트 실행을 막습니다. 일부 조회가 실패하면 확인 실패를 알리고 기존 목록을 유지합니다.

`tools/build.ps1` 전체를 통과했습니다. 두 런타임의 Core/Desktop 검사, 현재 모니터 DPI 및 100/125/150/200/250% 레이아웃 검사, 양방향 교차 런타임 TLS 전송, 현대 Windows용 및 Windows 7용 설치 파일 생성을 확인했습니다.

새 회귀 검사는 실제 트레이 항목을 실행해 인증된 로컬 호스트에서 일반 카탈로그와 Manager 카탈로그가 함께 조회되는지 확인합니다. 설치 파일 다운로드는 0회이며, 새 Manager 버전이 설치 실행 없이 메뉴에 남는 것을 확인했습니다. 빈 항목 숨김, 한 개의 확인 메뉴, 두 종류 업데이트의 동일 메뉴 표시, 트레이 표시·개수도 검사합니다.

도움말과 README의 메뉴 이름·사용 순서를 수정했습니다. 네이티브 메뉴 렌더링 자료는 로컬 `artifacts/tray-0.4.1/`에 있습니다. 실제 Windows 7 장비와 두 번째 물리 PC 검사는 별도이며 net48 검사는 현재 Windows에서 실행했습니다.
