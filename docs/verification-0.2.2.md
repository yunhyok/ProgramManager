# Program Manager 0.2.2 검증 기록

검증일: 2026-09-10. Windows 10 Pro 64비트(10.0.19045), 실제 배율 250%(240 DPI), .NET 8 및 .NET Framework 4.8.

## 원인과 변경

기존 동기화는 저장소 하나에 설치 파일이 없거나 후보가 모호하면 예외로 전체 작업을 중단했습니다. 저장소 선택 화면도 설치 파일 정보를 확인하지 않아 배포할 수 없는 항목을 선택할 수 있었습니다. 하단 진행 막대는 표시만 켜지고 GitHub 처리 수를 전달받지 않았습니다.

저장소 선택 화면이 Release 메타데이터를 먼저 검사하고 배포 가능 여부를 표시합니다. 새로 선택할 수 없는 항목은 체크를 비활성화하며, 전체 오류는 아래 설명 영역과 툴팁에 표시합니다. 설치 파일 패턴을 수정하면 받은 메타데이터로 다시 판정하고, ‘다시 검사’로 GitHub 정보를 갱신합니다. 검사 중에는 저장 버튼을 비활성화하고 저장소 이름·처리 수·진행 막대를 표시합니다.

동기화는 저장소별로 성공·실패를 구분합니다. 정상 저장소를 반영하고 실패한 기존 저장소는 마지막 게시 항목을 유지합니다. 명시적으로 체크를 해제한 항목은 배포 목록에서 제외합니다. 취소와 최종 파일 저장 실패는 기존 게시 목록을 보존합니다. 동기화 진행률과 완료 후 실패 사유도 표시합니다.

## 실제 GitHub 검사

현재 PC의 기존 GitHub 인증을 사용해 계정의 저장소 90개를 검사했습니다. 기본 파일 선택 기준으로 배포 가능 19개, 설치 파일 부재·후보 확인 등으로 선택 불가 71개였습니다. 이는 검사 시점 결과이며 파일 패턴과 Release 변경에 따라 달라집니다.

격리된 데이터 폴더에서 실제 저장소 4개를 함께 동기화했습니다.

| 저장소 | 결과 |
| --- | --- |
| `yunhyok/Cap-Organizer` | 정상 반영 |
| `yunhyok/CapStack-Model-Studio` | 정상 반영 |
| `yunhyok/2025-08-25-verilog` | 설치 파일 없음, 건너뜀 |
| `yunhyok/20250614---backup` | 설치 파일 없음, 건너뜀 |

설치 파일 다운로드 없이 정상 프로그램 2개가 게시됐고 실패 2개는 별도 결과로 반환됐습니다. 실제 사용자 설정 파일은 바이트 단위로 동일했습니다. 사용자 배포 저장소 선택을 임의로 바꾸지 않았습니다. 증거는 `artifacts/preflight-live-0.2.2.log`, `artifacts/preflight-live-result-0.2.2/verification.json`입니다.

## 회귀 검사

Core Checks는 두 런타임에서 통과했습니다. 정상 항목과 설치 파일 없음·후보 중복·HTTP 404·잘못된 저장소/Release 응답을 섞어 처리했습니다. 실패한 기존 항목 보존, 정상 항목 업데이트, 타임아웃과 사용자 취소 구분, 저장 실패 시 원자적 보존, 명시적 선택 해제, 직접 게시 항목 보존, 카탈로그 용량·중복 충돌 격리, 진행 수와 설치 파일 다운로드 없음도 확인했습니다.

Desktop Checks는 검사 대기·진행·완료 상태, 선택 제한, 기존 실패 항목 보존과 해제, 파일 패턴 수정, 다시 검사, 취소를 두 런타임에서 확인했습니다. 중간 진행 값이 0과 최대값 사이로 증가하고 완료 시 전체 항목 수와 같아지는지 검사했습니다. 행 선택 시 이전 행의 오류가 남는 문제도 `CurrentCellChanged` 처리로 수정하고 재검증했습니다.

제품의 실제 폼 소스로 기존 화면과 새 동기화 결과 창을 실제 배율 및 100·125·150·200·250% 모의 크기에서 검사했습니다. 저장소 검사 중·완료 화면과 긴 오류 설명도 렌더링했습니다. 네이티브 ProgressBar 채움은 `DrawToBitmap` 이미지에 재현되지 않으므로 표시 여부와 실제 진행 값을 별도로 검증했습니다. 결과는 `artifacts/layout/net8`, `artifacts/layout/net48`에 있습니다.

`tools/build.ps1` 전체가 통과했습니다. 두 대상 제품 빌드, Core/데스크톱 검사, UI 배율 검사, 런타임 간 양방향 TLS 통신, 두 설치 파일 생성을 완료했습니다. 빌드 경고와 오류는 0개이며 로그는 `artifacts/build-0.2.2.log`에 있습니다.

## 현재 PC 설치

기존 0.2.1을 최종 Windows 10/11 설치 파일로 0.2.2로 업데이트했습니다. 설치 종료 코드 0, 설치된 465개 파일의 해시가 최종 게시 폴더와 일치합니다. 기존 프로그램 19개와 설정을 보존했으며, 설치 전후와 새 앱 실행 후 설정 파일이 바이트 단위로 동일합니다. 실제 설치본의 창 제목 `Program Manager 0.2.2`, 프로그램 19개 표시와 준비 완료 상태를 확인했습니다.

Windows 10/11 설치 파일은 51,055,563바이트, Windows 7용은 2,406,383바이트입니다. 설치 증거는 `artifacts/upgrade-verification-0.2.2.json`, `artifacts/upgrade-0.2.2.log`, 해시는 `artifacts/installers/SHA256SUMS.txt`에 있습니다.

Windows 7 실기기와 두 번째 물리 PC에서의 검증은 수행하지 않았습니다. 프로젝트에 GitHub 원격 저장소가 없어 Program Manager 자체의 원격 게시도 수행하지 않았습니다.
