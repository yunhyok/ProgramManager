# Program Manager 0.5.1 검증 기록

저장소 선택 화면에서 **시험판 포함**을 저장소 이름 바로 옆으로 옮겼습니다. 시험판으로만 배포할 수 있으면 **시험판 있음 · ‘시험판 포함’ 체크**, 정식판과 시험판을 함께 배포할 수 있으면 **시험판도 있음**을 표시합니다. 정식 릴리스가 있어도 설치 파일이 시험판에만 있는 경우를 포함합니다.

안내 여부는 이미 받은 릴리스 정보에 기존 배포 판정 규칙을 적용해 결정합니다. 시험판 태그만 있고 배포할 수 있는 파일이 없거나 메타데이터가 잘못된 경우에는 배포 가능한 시험판으로 안내하지 않습니다. 추가 GitHub 요청이나 설치 파일 다운로드는 하지 않습니다. 저장소별 기존 옵션과 카탈로그·전송 형식은 유지합니다.

## 검사

- .NET 8과 .NET Framework 4.8 제품 빌드 및 코어·데스크톱 검사 통과.
- 양방향 런타임 TLS 전송 검사 통과.
- 실제 배율과 100/125/150/200/250% 모의 배율 검사 통과.
- 시험판만 있는 저장소의 옵션 변경, 배포 선택, 해제, 저장 및 메타데이터 재사용 확인.
- 정식 릴리스에 파일이 없고 시험판에만 설치 파일이 있는 경우와 잘못된 시험판 메타데이터를 가진 경우 확인.
- 별도 읽기 전용 리뷰에서 배포 가능 여부에 따른 안내 개선을 반영했으며, 남은 기능·호환성 배포 차단점은 없었습니다.

로컬 전체 로그는 `artifacts/build-0.5.1.log`, 화면과 배율별 결과는 `artifacts/layout/`에 있습니다. Windows 7 실기기 실행과 현재 PC의 설치본 업데이트는 수행하지 않았습니다.
